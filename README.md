## 🚀 Proyecto destacado: Enterprise Infrastructure Lab

Un laboratorio de infraestructura virtualizada tipo *enterprise* que integra:

- **Segmentación de red** con VLANs (LAN, Gestión, Servicios) sobre pfSense
- **Seguridad perimetral** con Fortigate (DPI, control de acceso por identidad)
- **Gestión de identidad** con Active Directory (GPOs, RBAC)
- **Infraestructura como código** con Terraform (aprovisionamiento) y Ansible (configuración)
- **Observabilidad** con Prometheus + Grafana (dashboards y alertas en tiempo real)
- **Contenedores** orquestados con Docker y Kubernetes
